I read SPEC.md, which confirmed the task: implement `solve(xs: list[int]) -> int` that treats the list as a bracket sequence where a positive number opens a bracket and a negative number closes one, returning the deepest nesting level reached, or 0 if the sequence is ever unbalanced (a close with nothing open, or opens left over at the end).

My approach was a single linear scan with a running level counter and a max tracker. For each element: if it is positive, increment the level and update the deepest-so-far; if it is negative, decrement the level and immediately return 0 if the level drops below zero (a close with nothing open). After the loop, if the level is not exactly zero there are leftover opens, so I return 0; otherwise I return the deepest level recorded. This handles the empty list naturally (deepest stays 0, level stays 0, returns 0), and treats zero-valued entries as neither opening nor closing, which is the reasonable reading of "positive opens, negative closes."
