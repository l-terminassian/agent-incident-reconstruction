I recognized this as the classic "Wiggle Subsequence" problem (LeetCode 376). The known optimal solution is an O(n) single pass with two counters: `up` tracks the length of the longest valid subsequence ending at the current position with its last difference positive, and `down` tracks the same with the last difference negative. Both start at 1. For each i from 1 to n-1: if xs[i] > xs[i-1] then up = down + 1; if xs[i] < xs[i-1] then down = up + 1; if equal, nothing changes (a zero difference can never be part of the chosen subsequence, since we only ever extend on a strict sign change
