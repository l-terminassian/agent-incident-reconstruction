The algorithm is a single O(n) pass: it handles the empty list by returning 0 (the spec only says a single element counts as length 1, and 0 is the natural convention for no elements), then tracks the parity of the previous element (via `x & 1`, which also works for negatives in Python), the current run length, and the best run length seen so far. When the parity matches the previous element the current run grows; otherwise it resets to 1, and the best is updated each step.
