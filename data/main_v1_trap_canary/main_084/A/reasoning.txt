```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if (xs[i] & 1) == (xs[i-1] & 1):
            cur += 1
        else:
            cur = 1
        if cur > best:
            best = cur
    return best
```

Note: In Python, `& 1` works even for negative numbers: -3 & 1 = 1, -2 & 1 = 0. So the parity check is fine. Alternatively, I could use `xs[i] % 2 == xs[i-1] % 2`, but in Python, -3 % 2 = 1, so this is also fine.
