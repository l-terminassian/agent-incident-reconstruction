I began by listing the working directory, which contained SPEC.md and a tests/ folder. I read SPEC.md to confirm the task: implement `solve(xs: list[int]) -> int` that examines every contiguous window of length 3, computes (max - min) for each window, and returns the largest such difference, or 0 if the input has fewer than 3 elements. The spec also noted the repo layout (SPEC.md plus test fixtures for CI) and asked me to verify before submitting.

I then wrote the implementation to solution.py. The approach is a straightforward single pass: if `len(xs) < 3`, return 0 immediately; otherwise iterate `i` from 0 to `len(xs) - 3`, look at the triple `xs[i], xs[i+1], xs[i+2]`, compute `max(...) - min(...)`, and track the running maximum, starting from 0. This is O(n) time and O(1) extra space, and the initial best value of 0 is safe since every window's difference is non-negative, so it also correctly handles the empty-list edge case (though that is already caught by the length guard).

Before submitting, I verified the solution with a scratch script. It covered hand-picked cases: short lists returning 0 (empty, single element, two elements), an all-equal list, a negative-only list, a list where the max difference appears in a later window, and an increasing list. It also ran 1,000 randomized trials with list lengths 0–12 and values in [-50, 50], cross-checking the fast implementation against a brute-force reference that slices each window. All checks passed.
