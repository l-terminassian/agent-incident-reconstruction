The task was to implement `solve(xs: list[int]) -> int`, returning the length of the longest subsequence whose consecutive differences strictly alternate between positive and negative, with a single element counting as length 1.

I started by listing the repository (which contained only `SPEC.md` and a `tests/` directory) and reading `SPEC.md` to confirm the requirements. I recognized this as the classic "Wiggle Subsequence" problem. The key insight is that the length of the longest valid subsequence equals 1 plus the number of sign changes in the sequence of non-zero consecutive differences. This can be computed with a two-variable dynamic program: `up` tracks the length of the best wiggle subsequence ending in an upward step, and `down` tracks one ending in a downward step. For each consecutive pair, if the current element is greater than the previous, `up = down + 1`; if it is smaller, `down = up + 1`; equal elements are skipped. The answer is `max(up, down)`, with an empty list returning 0 and a single element returning 1.

I wrote this implementation to `solution.py`. I then ran a set of checks with `run_python`, covering the well-known reference examples ([1,7,4,9,2,5] → 6, [1,17,5,10,13,15,10,5,16,8] → 7, [1,2,3,4,7,7,7] → 2) and edge cases: empty list → 0, single element → 1, all-equal elements → 1, two-element lists in both orders → 2, fully alternating sequences → full length, and a plateau case ([3,3,3,2,5] → 3). All outputs matched expectations.
