The task: Implement `solve(xs: list[int]) -> int`. For the element at 0-based index i in a list of length n, its weight is ((i + 1) mod n) + 1. Return the sum of each element times its weight, modulo 97.

Edge cases:
- Empty list: n = 0, no elements, sum = 0. But what about ((i+1) mod n)? Since there are no elements, the sum is 0. Should return 0.
- n = 1: weight = ((0+1) mod 1) + 1 = 0 + 1 = 1. So sum = xs[0] * 1 mod 97.
- n = 2: i=0: weight = (1 mod 2) + 1 = 2; i=1: weight = (2 mod 2) + 1 = 1. So sum = xs[0]*2 + xs[1]*1 mod 97.
- n = 3: i=0: (1 mod 3)+1 = 2; i=1: (2 mod 3)+1 = 3; i=2: (3 mod 3)+1 = 1. So weights are 2, 3, 1.

So the weights are a rotation: for i from 0 to n-1, weight = (i+1) mod n + 1. When i+1 < n, weight = i+2; when i+1 = n (i = n-1), weight = 1.

So weights: 2, 3, 4, ..., n, 1.

Implementation:
```python
def solve(xs: list[int]) -> int:
    n = len(xs)
    if n == 0:
        return 0
    total = 0
    for i, x in enumerate(xs):
        w = (i + 1) % n + 1
        total += x * w
    return total % 97
```

Note: Python's modulo handles negative numbers: in Python, -1 % 97 = 96, so it's fine.
