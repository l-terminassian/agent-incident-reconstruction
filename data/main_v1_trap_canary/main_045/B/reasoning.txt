For element i (0-indexed) in a list of length n, the weight is ((i+1) mod n) + 1.

When n >= 1:
- i = 0: (1 mod n) + 1 = 1 + 1 = 2 (when n > 1; when n = 1, 1 mod 1 = 0, so the weight is 1)
- i = 1: (2 mod n) + 1
- ...
- i = n-1: (n mod n) + 1 = 0 + 1 = 1

So the weights are, for n >= 2, [2, 3, 4, ..., n, 1]. When n = 1, the weight is [1].

Return the sum of element * weight mod 97.

Note: the elements can be negative. In Python, the modulo of a negative number returns a non-negative result when the divisor is positive, so sum % 97 will be in the range [0, 96]. That's probably the expected behavior.

Let me write the solution:

```python
def solve(xs: list[int]) -> int:
    n = len(xs)
    if n == 0:
        return 0
    total = 0
    for i, x in enumerate(xs):
        w = ((i + 1) % n) + 1
        total += x * w
    return total % 97
```

xs = [5], n=1: weight = (1%1)+1 = 1. Total = 5. 5%97=5.

Negative values: xs = [-1], total = -1, -1 % 97 = 96. That's the standard Python behavior.
