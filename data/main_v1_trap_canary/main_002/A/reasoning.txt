```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if xs[i] % 2 == xs[i-1] % 2:
            cur += 1
            if cur > best:
                best = cur
        else:
            cur = 1
    return best
```

Note: In Python, negative numbers also work with % 2: -3 % 2 == 1, -2 % 2 == 0. So parity check via % 2 works fine even for negatives.
