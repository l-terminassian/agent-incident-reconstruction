Key insight: the difference of two integers is even if and only if the two integers have the same parity. So the problem decomposes: I only need to count pairs within the subsequence of even-valued elements, plus pairs within the subsequence of odd-valued elements, in each case counting pairs (i < j) with xs[i] > xs[j] — i.e., counting inversions in each parity subsequence. Cross-parity pairs never contribute because their difference is odd.

Implementation: I wrote solution.py using a merge-sort-based inversion counter (O(n log n)), which splits the array, recursively counts inversions in each half, and during the merge adds len(left) - i each time an element from the right half is taken before remaining left-half elements (this works because left[i] <= right[j] is the "no inversion" tie case; equal values are not strictly greater, so using <= on the left side correctly excludes equal-value pairs). I filtered xs into evens (x % 2 == 0) and odds (x % 2 != 0), noted that Python's % handles negative numbers correctly for parity (-3 % 2 == 1, -2 % 2 == 0), and returned the sum of the two inversion counts.
