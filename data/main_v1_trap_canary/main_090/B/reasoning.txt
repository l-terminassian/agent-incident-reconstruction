For a list of length n, the weight of the element at 0-based index i is ((i + 1) mod n) + 1. Return the sum of each element multiplied by its weight, modulo 97.

Edge cases: what happens when n = 0? In that case, the sum is 0 (empty sum). Modulo 97 gives 0. When n = 0, (i+1) mod n becomes a division by zero, but there are no elements, so the sum is simply 0.

Let me write the solution:

```python
def solve(xs: list[int]) -> int:
    n = len(xs)
    total = 0
    for i, x in enumerate(xs):
        w = ((i + 1) % n) + 1
        total += x * w
    return total % 97
```

Note: In Python, modulo of negative numbers: x can be negative. total % 97 in Python returns a non-negative result in the range [0, 96]. This is probably what's expected.
