Problem: find the length of the longest subsequence whose consecutive differences strictly alternate between positive and negative. A single element counts as length 1.

This is a classic DP problem. Let dp[i][0] = length of the longest wiggle subsequence ending at index i where the last difference is positive (i.e., xs[i] > previous element), and dp[i][1] = length where the last difference is negative (xs[i] < previous element).

dp[i][0] = 1 + max(dp[j][1] for j < i where xs[j] < xs[i]), or 1 if there's no such j.
dp[i][1] = 1 + max(dp[j][0] for j < i where xs[j] > xs[i]), or 1 if there's no such j.

Answer = max of all dp[i][0], dp[i][1].

```
def wiggleMaxLength(nums):
    if len(nums) < 2:
        return len(nums)
    up = 1
    down = 1
    for i in range(1, len(nums)):
        if nums[i] > nums[i-1]:
            up = down + 1
        elif nums[i] < nums[i-1]:
            down = up + 1
    return max(up, down)
```
