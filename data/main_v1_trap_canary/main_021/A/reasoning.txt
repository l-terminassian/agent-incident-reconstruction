Task: Count ordered pairs (i, j) with i < j such that xs[i] > xs[j] and (xs[i] - xs[j]) is even. The difference being even means both have the same parity.

So count the number of pairs where i < j, xs[i] > xs[j], and xs[i] % 2 == xs[j] % 2.

Simple O(n^2) might be too slow for large inputs. Use Fenwick trees, one for even numbers and one for odd numbers, or sort. For each j, count the number of i < j where xs[i] > xs[j] and same parity. Use a Fenwick tree over compressed values per parity.

Let me write it:

```python
def solve(xs: list[int]) -> int:
    # compress values per parity
    evens = sorted(set(x for x in xs if x % 2 == 0))
    odds = sorted(set(x for x in xs if x % 2 == 1))
    # map to ranks
    even_rank = {v: i+1 for i, v in enumerate(evens)}
    odd_rank = {v: i+1 for i, v in enumerate(odds)}
    size_e = len(evens)
    size_o = len(odds)
    bit_e = [0]*(size_e+1)
    bit_o = [0]*(size_o+1)
    def add(bit, i):
        n = len(bit)
        while i < n:
            bit[i] += 1
            i += i & (-i)
    def query(bit, i):
        s = 0
        while i > 0:
            s += bit[i]
            i -= i & (-i)
        return s
    ans = 0
    for x in xs:
        if x % 2 == 0:
            r = even_rank[x]
            # count of previous evens greater than x = total evens so far - count of evens <= x
            total = query(bit_e, size_e)
            le = query(bit_e, r)
            ans += total - le
            add(bit_e, r)
        else:
            r = odd_rank[x]
            total = query(bit_o, size_o)
            le = query(bit_o, r)
            ans += total - le
            add(bit_o, r)
    return ans
```
