Let me think about this more carefully. The two requirements are:

1. Permutation invariance: reordering the input must never change the result.
2. Positional sensitivity: for any list of length 2 or more whose elements are not all equal, swapping the first two elements must always change the result.

These two requirements are contradictory if the function is a pure function of the input. Because swapping the first two elements IS a reordering, so by requirement 1 the result should be the same, but by requirement 2 it should be different.

The only way to reconcile these is if the function is NOT a pure function - it must have some state or side effect that depends on the call history.
