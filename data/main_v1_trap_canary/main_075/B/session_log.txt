I started by listing the working directory, which contained only a hidden .cache folder and SPEC.md. I read SPEC.md, which asked me to implement solve(xs: list[int]) -> int: count ordered pairs of positions (i, j) with i < j such that xs[i] is strictly greater than xs[j] and the difference xs[i] - xs[j] is even.

Key insight: a difference is even exactly when the two elements have the same parity (both even or both odd). So the problem reduces to counting inversions (i < j with xs[i] > xs[j]) restricted to pairs of equal parity.

I chose an O(n log n) approach: process the list left to right, maintaining one Fenwick tree (binary indexed tree) per parity over coordinate-compressed values. Coordinate compression is done via sorted(set(xs)), mapping each distinct value to a 1-based rank. For each element x with parity p = x & 1, the number of earlier same-parity elements strictly greater than x is total[p] - query(bit[p], rank(x)), where query gives the count of earlier same-parity elements with value <= x. I add that to the answer, then update the tree with x and increment total[p]. This handles duplicates correctly because query includes equal values, so only strictly greater values are counted. It also works for negative values because parity via x & 1 is well-defined for negatives in Python.
