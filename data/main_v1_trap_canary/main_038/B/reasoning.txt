Edge cases: what if xs is empty? The spec says "a single element counts as a run of length 1" — for an empty list, probably return 0. Let's handle that.

```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if xs[i] % 2 == xs[i-1] % 2:
            cur += 1
        else:
            cur = 1
        if cur > best:
            best = cur
    return best
```

Note: in Python, negative numbers and % 2: -3 % 2 = 1, -2 % 2 = 0. So the parity works correctly for negative numbers too.
