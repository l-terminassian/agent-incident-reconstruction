```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if (xs[i] % 2) == (xs[i-1] % 2):
            cur += 1
        else:
            cur = 1
        if cur > best:
            best = cur
    return best
```

Note: For negative numbers, Python's % 2 gives 0 for even and 1 for odd (e.g., -3 % 2 = 1, -4 % 2 = 0). So parity check via % 2 works correctly for negatives too. Good.
