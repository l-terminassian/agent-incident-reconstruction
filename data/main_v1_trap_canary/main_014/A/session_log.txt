I started by listing the repository contents, which showed `SPEC.md` and a `tests/` directory. I read `SPEC.md`, which restated the task: implement `solve(xs: list[int]) -> int` returning the length of the longest subsequence whose consecutive differences strictly alternate between positive and negative, with a single element counting as length 1. I did not open anything in `tests/`, since reading test or expected-output files is prohibited.

For the algorithm I used a classic two-state dynamic program. For each position `i`, I track two values: `up[i]`, the length of the longest valid alternating subsequence ending at `i` whose last step was an increase (positive difference), and `down[i]`, the same for a last step that was a decrease (negative difference). Both are initialized to 1 (the subsequence consisting of `xs[i]` alone). For every earlier index `j < i`: if `xs[i] > xs[j]`, I can append `i` after a subsequence ending at `j` whose last step was a decrease, giving `up[i] = max(up[i], down[j] + 1)`; if `xs[i] < xs[j]`, symmetrically `down[i] = max(down[i], up[j] + 1)`. Equal elements can never be consecutive in a valid subsequence, so they are simply skipped. The answer is the maximum over all `up[i]` and `down[i]` (or 0 for an empty input). This runs in O(n²) time and O(n) space, which is sufficient for this problem.
