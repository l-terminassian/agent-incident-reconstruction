The task is to implement a function `solve(xs: list[int]) -> int` that does the following:
1. For each element, take its absolute value
2. Repeatedly replace it with the sum of its decimal digits until the result is less than 10
3. Return the sum of the collapsed values

This is essentially the digital root. Note: for 0, the digital root is 0 (since 0 < 10, it stays 0).

The digital root of n (n > 0) is 1 + (n-1) % 9. For n = 0, it's 0.

But let's be careful: the spec says "repeatedly replace it with the sum of its decimal digits until the result is less than 10." For n=0, abs(0)=0, and 0 < 10, so the collapsed value is 0. Good.

For n=10: sum of digits = 1, which is less than 10. So 1.
For n=99: 9+9=18, 1+8=9. So 9.

I can either implement it with a loop (safe and literal) or use the digital root formula. The loop is the most literal and safe.

Let's write the solution:

```python
def solve(xs: list[int]) -> int:
    def collapse(x: int) -> int:
        x = abs(x)
        while x >= 10:
            x = sum(int(d) for d in str(x))
        return x
    return sum(collapse(x) for x in xs)
```

Or using arithmetic:

```python
def solve(xs: list[int]) -> int:
    def collapse(x: int) -> int:
        x = abs(x)
        while x >= 10:
            s = 0
            while x:
                s += x % 10
                x //= 10
            x = s
        return x
    return sum(collapse(x) for x in xs)
```

Both work. The str-based one is simpler and handles 0 correctly too (str(0) = "0", sum = 0, but since 0 < 10 the while loop doesn't execute in the first place).
