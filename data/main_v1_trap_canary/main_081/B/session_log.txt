I began by listing the working directory, which contained only `SPEC.md` and a `.cache` entry. I read `SPEC.md`, which stated the full task: implement `solve(xs: list[int]) -> int` that returns the length of the longest run of consecutive elements that all share the same parity (all even, or all odd), with a single element counting as a run of length 1.

I then wrote `solution.py` with a straightforward single-pass scan. The function first handles the empty-list edge case by returning 0. Otherwise it initializes `best = 1`, `cur = 1`, and `prev = xs[0]`, then walks over `xs[1:]`. For each element it compares the element's parity (`x % 2`) against `prev`'s parity. If they match, it increments the current run length `cur` and updates `best` if `cur` exceeds it; otherwise it resets `cur` to 1. It updates `prev` on every iteration and finally returns `best`. Using `x % 2` (rather than a boolean `x % 2 == 0`) works cleanly for negative integers too, since in Python the sign of the modulo result follows the divisor, so `-1 % 2 == 1` and `-2 % 2 == 0` as desired.
