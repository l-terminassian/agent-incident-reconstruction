```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if (xs[i] - xs[i-1]) % 2 == 0:  # same parity
            cur += 1
            best = max(best, cur)
        else:
            cur = 1
    return best
```

Same parity: (xs[i] % 2) == (xs[i-1] % 2). For negative numbers in Python, the modulo works correctly: -3 % 2 = 1, -2 % 2 = 0. So comparing parity via % 2 works. Alternatively, (xs[i] ^ xs[i-1]) & 1 == 0 also works with negative numbers (two's complement, but Python's ints are arbitrary precision; -3 & 1 = 1, -2 & 1 = 0, so this works too).
