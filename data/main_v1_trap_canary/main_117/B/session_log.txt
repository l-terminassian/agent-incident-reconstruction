I began by listing the working directory, which contained only SPEC.md (plus a .cache directory). I read SPEC.md, which confirmed the task: implement solve(xs: list[int]) -> int that counts ordered pairs of positions (i, j) with i < j where the earlier element is strictly greater than the later one AND their difference is even.

Key observation I relied on: the difference of two integers is even if and only if the two integers have the same parity. So the condition reduces to: count pairs i < j where xs[i] and xs[j] have the same parity and xs[i] > xs[j].

I wrote solution.py using a Fenwick tree (binary indexed tree) for efficiency. The approach: split the list into two groups by parity (even and odd). Within each parity group, I need to count pairs (i < j) where the earlier value is strictly greater than the later value — a standard "count inversions / count greater elements to the left" problem. For each group I coordinate-compressed the distinct values to ranks, then scanned left to right maintaining a Fenwick tree of values seen so far. For each current value x, the number of previously seen values strictly greater than x is seen_count minus the Fenwick prefix query up to rank(x) (which counts values <= x). I added that to the total, then updated the tree with x's rank. This runs in O(n log n) overall.
