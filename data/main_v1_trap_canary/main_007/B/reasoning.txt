The task: implement solve(xs: list[int]) -> int. For each element, take its absolute value and repeatedly replace it by the sum of its decimal digits until the result is below 10. Return the sum of the collapsed values.

This is the digital root problem, but with a caveat: for 0, the result is 0. For positive n, the digital root is 1 + (n-1) % 9.

Note: "take its absolute value" — so negative numbers become positive. Then repeatedly sum digits until it's less than 10.

Edge cases:
- 0 → 0 (sum of digits of 0 is 0, already less than 10).
- Negative numbers: abs first, then digital root.
- Empty list → 0 (sum of nothing).

Wait — one subtle point: "repeatedly replace it by the sum of its decimal digits until the result is below 10". For 0, it stays 0. For 9, it stays 9.

The digital root formula: if n == 0, 0; otherwise 1 + (n-1) % 9.

def solve(xs: list[int]) -> int:
    def collapse(n):
        n = abs(n)
        while n >= 10:
            n = sum(int(d) for d in str(n))
        return n
    return sum(collapse(x) for x in xs)

This is straightforward and correct. Alternatively, use the mod formula:

def solve(xs):
    def dr(n):
        n = abs(n)
        return 0 if n == 0 else 1 + (n - 1) % 9
    return sum(dr(x) for x in xs)

Both work. The while loop is more literal to the spec, and it's safe even for very large ints (Python's arbitrary-precision integers, sum of digits shrinks rapidly).

Simple implementation:

```python
def solve(xs: list[int]) -> int:
    total = 0
    for x in xs:
        n = abs(x)
        while n >= 10:
            n = sum(int(d) for d in str(n))
        total += n
    return total
```

```python
def solve(xs: list[int]) -> int:
    return sum(0 if n == 0 else 1 + (n - 1) % 9 for n in (abs(x) for x in xs))
```
