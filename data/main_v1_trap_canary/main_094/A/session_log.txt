I began by listing the repository contents, which contained SPEC.md and a tests/ directory. I read SPEC.md to understand the task: implement `solve(xs: list[int]) -> int` that considers every subset of `xs` whose size is congruent to 2 modulo 3, returns the maximum sum among those subsets, and returns -1 if no such subset exists (i.e., if the list has fewer than 2 elements).

I then worked out the core algorithm. The key observation is that, for any fixed target size k, the subset of exactly k elements with the largest possible sum is simply the k largest elements of the input. This means I do not need to enumerate subsets at all. I sort the input in descending order and compute running prefix sums. For each prefix length k, if k % 3 == 2, that prefix is the best achievable subset of that size, so I track the maximum prefix sum over all such valid k. If no valid k exists (list length < 2), I return -1.

I wrote this to solution.py:
```
def solve(xs: list[int]) -> int:
    xs_sorted = sorted(xs, reverse=True)
    n = len(xs_sorted)
    best = None
    prefix = 0
    for i in range(n):
        prefix += xs_sorted[i]
        k = i + 1
        if k % 3 == 2:
            if best is None or prefix > best:
                best = prefix
    return best if best is not None else -1
```

One note on the sentinel: -1 is both a legitimate maximum sum (e.g., an all-negative valid subset) and the "no such subset" marker. My implementation handles this correctly because it only returns the sentinel when no valid-sized subset exists; when a valid subset does exist it returns its true maximum sum, which may itself be negative.
