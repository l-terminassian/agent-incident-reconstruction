I was asked to implement `solve(xs: list[int]) -> int`, which must return the length of the longest run of consecutive elements that all share the same parity (all even or all odd), where a single element counts as a run of length 1.

I began by listing the working directory, which contained a `.cache` folder and a `SPEC.md` file. I read `SPEC.md` to confirm the exact specification, which matched the task description: find the longest contiguous run of elements sharing parity.

My approach was a single linear pass with two running counters. I handle the empty-list edge case explicitly (returning 0, since there is no run when the list is empty). For a non-empty list I initialize both `best` and `cur` to 1, then walk through the list comparing the parity of each adjacent pair using the bit trick `xs[i] & 1 == xs[i-1] & 1` (which correctly handles negative numbers, since parity is preserved under the modulo-2 interpretation of the low bit). When two neighbors match in parity I increment the current run and update `best`; otherwise I reset `cur` to 1. This runs in O(n) time and O(1) extra space. I wrote this to `solution.py`.
