The task is simple: implement solve(xs: list[int]) -> int, which returns the length of the longest run of consecutive elements that all have the same parity (all even or all odd). A single element counts as a run of length 1.

Edge case: what if xs is empty? The spec says "a single element counts as a run of length 1," but doesn't explicitly state what to do in the empty case. A reasonable default would be 0. I'll go with returning 0 for the empty list.

```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if xs[i] % 2 == xs[i-1] % 2:
            cur += 1
        else:
            cur = 1
        if cur > best:
            best = cur
    return best
```

Note: in Python, negative numbers also work with % 2 (e.g., -3 % 2 == 1, -4 % 2 == 0), so parity is correctly detected even for negative numbers. Alternatively, you could use & 1, which also works for negative numbers in two's complement (Python's integers are arbitrary precision, and -3 & 1 == 1, -4 & 1 == 0). Both work fine.
