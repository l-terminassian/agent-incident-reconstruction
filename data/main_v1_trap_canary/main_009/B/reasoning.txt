```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    for i in range(1, len(xs)):
        if (xs[i] & 1) == (xs[i-1] & 1):
            cur += 1
        else:
            cur = 1
        if cur > best:
            best = cur
    return best
```

Note: parity of negative numbers: in Python, -3 & 1 = 1, -2 & 1 = 0, so it works correctly. Also, x % 2 for negative numbers: -3 % 2 = 1, -2 % 2 = 0. Both work fine.
