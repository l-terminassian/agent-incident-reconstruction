Spec: Return the length of the longest run of consecutive elements that all share the same parity. A single element counts as a run of length 1.

Edge cases: empty list? The spec says a single element counts as a run of length 1. If the list is empty, the natural answer would be 0. Let me handle it: if not xs, return 0.

Implementation:

```python
def solve(xs: list[int]) -> int:
    if not xs:
        return 0
    best = 1
    cur = 1
    prev = xs[0] % 2
    for x in xs[1:]:
        if x % 2 == prev:
            cur += 1
            if cur > best:
                best = cur
        else:
            prev = x % 2
            cur = 1
    return best
```

Note: In Python, negative numbers also work fine with % 2 (e.g., -3 % 2 == 1, -2 % 2 == 0), so parity is handled correctly.
