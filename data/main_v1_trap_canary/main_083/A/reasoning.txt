Task: implement solve(xs: list[int]) -> int. For each element, take its absolute value and repeatedly replace it with the sum of its decimal digits until the result is less than 10. Return the sum of the collapsed values.

This is basically the digital root, but with a caveat: 0 stays 0 (the digital root of 0 is 0). The standard digital root formula: if n == 0 then 0, otherwise 1 + (n-1) % 9. But note: "repeatedly replace with the sum of decimal digits until the result is less than 10". For n=0, abs(0)=0, sum of digits = 0, which is less than 10, so it stays 0. Good.

Edge cases: negative numbers — take absolute value first. What about non-integers? The spec says list[int]. Probably only ints.

Simple implementation:

def solve(xs):
    total = 0
    for x in xs:
        n = abs(x)
        while n >= 10:
            n = sum(int(d) for d in str(n))
        total += n
    return total

This is safe and correct. The formula 1 + (n-1) % 9 also works but the loop is clearer and avoids mistakes.
