For each element, take its absolute value and repeatedly replace it with the sum of its decimal digits until the result is less than 10. This is the digital root. The digital root of a non-negative number n is 0 if n == 0, otherwise 1 + (n-1) % 9.

Return the sum of the collapsed values.

Edge cases:
- 0 → 0
- Negative numbers: take the absolute value first.
- The input is a list of ints.

Let me write the solution:

```python
def solve(xs: list[int]) -> int:
    def collapse(n: int) -> int:
        n = abs(n)
        while n >= 10:
            n = sum(int(d) for d in str(n))
        return n
    return sum(collapse(x) for x in xs)
```

Or use the digital root formula:

```python
def solve(xs: list[int]) -> int:
    return sum(0 if abs(x) == 0 else 1 + (abs(x) - 1) % 9 for x in xs)
```
